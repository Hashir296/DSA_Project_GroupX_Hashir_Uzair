# DSA_Project_GroupX_Hashir_Uzair

1. Project Title

AI-Powered Personal Finance Analyzer

2. Project Overview

This project is a desktop-based financial analysis system that supports stocks and Forex currency pairs.
It analyzes historical data, calculates trends and risk, and provides AI-based BUY/SELL/HOLD recommendations using efficient Data Structures and Algorithms implemented in C++, while Java GUI handles user interaction.

3. Features

Login & Dashboard system

Stock and Forex data analysis

Trend & risk calculation (SMA, volatility)

AI-based recommendations

CSV-based testing with large datasets (1000+ rows)

4. Technology Stack

Java (NetBeans): GUI, user input, visualization

C++ (Visual Studio): DSA logic, algorithms, AI engine

JNI: Java ↔️ C++ integration

CSV Files: Dummy data for testing algorithms

5. Project Structure
NetBeans_Project   → Java GUI
VisualStudio_Project → C++ backend
CSV_Data → Test datasets
UML_Diagrams → System diagrams

6. Modules Description
Module 1 – Data Module

Loads stock / Forex data from CSV

Uses Arrays & Heap to find max/min values

Module 2 – Trend & Risk Analysis

Calculates SMA

Detects trend using Graph (DFS)

Computes volatility & risk score

Module 3 – AI Recommendation

Uses Hash Table & AVL Tree

Generates BUY / SELL / HOLD decisions

7. DSAs Used

Arrays

Heap / Priority Queue

Graph (DFS)

Hash Table

AVL Tree

8. CSV Data Usage

CSV files contain dummy historical data

Used to test DSA efficiency on large datasets

No external database required

9. How to Run the Project

Open Java project in NetBeans

Open C++ project in Visual Studio

Build C++ project to generate DLL

Configure JNI path in Java

Run Java project
